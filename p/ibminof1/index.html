OpenFOAM应用 - foam extend 浸没边界法(1)：算例设置和运行

在foam-extend 4.0中使用浸没边界法计算的基本步骤

Jun 25, 2025
阅读时长: 4 分钟

一 浸没边界法概述

浸入式边界方法(immersed boundary method, IBM)是一种非常适用于复杂边界及运动边界的CFD方法。相较于贴体网格方法，浸没边界法将内部边界表示为一系列拉格朗日点，在笛卡尔网格中建立对内部边界的建模，避免了贴体网格复杂的网格生成过程和动网格中的网格运动过程。

OpenFOAM现行版本中，ESI和org版本皆没有浸没边界法的植入，IBM的使用仅限于foam-extend相关版本。由于发布时间较早，foam-extend包含了许多老版本OF的操作逻辑。本文将简述如何在fe4.0中使用浸没边界法，并在后续文章中详细讨论浸没边界法的原理和实现。

二 单相流动边界求解器：icoDyMIbFoam

fe4.0中，单相流浸没边界法的求解器包括稳态的simpleIbFoam，瞬态的icoIbFoam, 以及在其基础上衍生出的支持动网格（动边界）的icoDyMIbFoam求解器。本章节以相对较为复杂的icoDyMIbFoam为例说明，示例算例为 /tutorials/immersedBoundary/movingCylinderInChannelIco。

#!/bin/sh

其中，blockMesh生成二维笛卡尔网格，save文件夹中包含了用于替换生成的polymesh中boundary文件的boundary文件，需要在生成网格后复制替换。该步骤会在后文中详细说明。复制0文件夹后，在运行求解器之前首先使用potentialIbFoam进行初始化，运行收敛后运行icoDyMIbFoam。（有关于为何要先运行potentialIbFoam的原因目前暂不明确）

2.2 浸没边界的定义和识别

浸没边界的模型文件位于constant/triSurface中，存储为.ftr文件格式。实际使用中，可以通过surfaceConvert命令在triSurface文件夹下将.stl文件转化为.ftr文件。

1

surfaceConvert model.stl model.ftr

三 两相流求解器 interIbFoam

interIbFoam为支持浸没边界的两相流求解器，不包含动边界支持。本章节采用的示例算例位于tutorials/immersedBoundary/cylBumpInterIbFoam。

#!/bin/sh
# Source tutorial run functions
. $WM_PROJECT_DIR/bin/tools/RunFunctions

# Get application name
application="interIbFoam"

runApplication blockMesh
\cp -f save/boundary constant/polyMesh/

mkdir 0
cp 0_org/* 0/

runApplication setFields

runApplication $application

注意到，interIbFoam作为多相流求解器，在前处理阶段需要使用setFields命令初始化场。然而，不同于icoIbFOAM和icoDyMIbFoam，该求解器无需使用potentialIbFoam初始化。

3.2 浸没边界边界条件

相较于单相流求解器，interIbFoam需要设定相alpha1的边界条件。（不同于新版本OpenFOAM，相不以"alpha.phasename"表示，而是将其中某一项表示为alpha1，第二相表示为alpha0=1-alpha1。）
